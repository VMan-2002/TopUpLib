# TopUpLib
My cool Balatro library mod

Includes some cool customization features for the players 😎

## Customization
Players can customize the following via the mod's config menu:
- UI Element Shape
	- The shape of UI elements
	- Default options: Default, Rectangle, Rounded Rectangle, Circle, Cat Emoji
- Font
	- The font used in English
	- Default options: mx6x11, Oswald, TerranceBig, Comic Sans MS

## Update check
Currently this only checks for mod's requirements/recommendations.
This requires a `topuplib_meta.json` in the mod's folder.

## Testing features
When [DebugPlus](https://github.com/WilsontheWolf/DebugPlus) is installed and enabled,
the following testing features become available:
- Top Joker (1e100 Chips and Mult)
- Top Deck (+990 hands/discards, +9e8 joker/consumable slots, +$9e5)
- Top Sleeve (Same as Top Deck, but as a [Card Sleeve](https://github.com/larswijn/CardSleeves))
- Max & Finn (Top Deck and Top Joker respectively, as [Partners](https://github.com/Icecanno/Partner-API/)) (WIP)
- Top Blind (1e280X base)
- Disapproving Blind (Debuff cards, and you can cycle between categories)
- Prohibitive Blind (All hands are not allowed)
